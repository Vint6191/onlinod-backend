ONLINOD 180 — Dialogs DB + CRM DB — проверенная редакция 27.10.2026

Это полные исходники Desktop180 и Backend180 на основе актуала178.
Папки node_modules, dist, локальная история, ключи и настройки не включены.

1. Backend: создайте две отдельные пустые PostgreSQL базы — dialogs и crm.
   Добавьте DIALOGS_DATABASE_URL и CRM_DATABASE_URL в окружение backend.
   Они должны отличаться между собой и от основной DATABASE_URL.
   Адреса баз и пароли НЕ добавляются в Desktop.
2. Выполните на backend npm ci (при чистой установке), затем
   npm run prisma:migrate. После успешной установки запускайте backend.
   Подробности, лимиты и восстановление: CONVERSATION_STORAGE.md в backend.
3. Обновите Desktop вместе с backend. На существующей установке:
   npm run dev. Для чистой установки сначала npm ci и настройка native
   better-sqlite3 для вашей версии Electron (npm run rebuild:native).

Старые локальные файлы истории/CRM не удаляются и автоматически не импортируются.
Новый серверный архив начинает сбор со своей даты активации.
По модели действует лимит 200000000 учитываемых байт; отдельный физический
лимит ветки PostgreSQL задаётся CONVERSATION_BRANCH_MAX_BYTES.

Исправлено при повторной проверке: защита состояния сканирования после смены
устройства/эпизода; независимый запуск основного backend при временной
недоступности Dialogs/CRM; восстановление очереди и чтение сохранённого
результата после суток офлайна; защита версии ручных CRM-правок; повтор
события покупки после изменения сообщения.
Схемы v1 не изменены. Уже созданные базы не пересоздавать и данные не сбрасывать.
Desktop и backend этой редакции обновляются вместе.

Проверены сборка и типы Desktop, 168 выбранных desktop-тестов, 3994 серверных
теста (96 пропущены), SQL-сценарии двух независимых PGlite баз, в том числе
через настоящий Prisma и PostgreSQL wire protocol. Пройден сквозной сценарий
сканер → клиент/очередь SQLite → сервер → SQL с потерей ответа и перезапуском.
Нативный PostgreSQL проверяется отдельным включённым GitHub workflow.
Этот workflow, Windows Electron, живые OnlyFans-сессии и ваш Neon здесь не запускались.
